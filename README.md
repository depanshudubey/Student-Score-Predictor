# 🤖 Student Score Predictor

A Machine Learning web application that predicts a student's final score based on study hours, attendance, sleep hours, and previous academic performance.

## 🌐 Live Demo

https://student-score-predictor-rnul.onrender.com

## 📂 GitHub Repository

https://github.com/depanshudubey/Student-Score-Predictor

## 🚀 Features

- Predicts student's final score
- Linear Regression Machine Learning model
- R² Score and MAE evaluation
- Interactive student input chart
- Responsive dark-themed UI
- Flask-based web application
- Deployed online using Render

## 🧠 Machine Learning

### Algorithm
Linear Regression

### Input Features
- Hours Studied
- Attendance
- Sleep Hours
- Previous Score

### Target
Final Score

## 📊 Model Performance

- R² Score: approximately 0.997
- MAE: approximately 0.75

- Python

- HTML
