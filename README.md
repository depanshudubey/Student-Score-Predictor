# 🤖 Student Score Predictor

A Machine Learning web application that predicts a
student's final score based on study hours, attendance,
sleep hours, and previous score.

## 🚀 Features

- Student final score prediction
- Linear Regression model
- R² Score and MAE evaluation
- Interactive input analysis chart
- Responsive dark UI
- Flask web application

## 🛠️ Technologies

- Python
- Pandas
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript
- Chart.js

## 🧠 Machine Learning

### Algorithm

Linear Regression

### Input Features

- Hours Studied
- Attendance
- Sleep Hours
- Previous Score

### Target

Final Score

## 📊 Model Performance

R² Score: approximately 0.997

MAE: approximately 0.75

These results are from the test split of the sample dataset.
